# フォレンジックレポート

> [!IMPORTANT]
> **書き方の原則**
> - 事実と推測を分ける。各所見に**確度**を付ける
> - 「安全です」「バックドアはありませんでした」と断定しない
> - **確認した範囲 / 未確認の範囲 / 確認不能の範囲**を必ず併記する
> - 「ログに記録がない」は「起きていない」ではない
>
> 確度は4段階:
>
> | 確度 | 意味 |
> |---|---|
> | **確定** | ログや設定ファイルに直接記録されている |
> | **強く示唆** | 複数の独立した記録が整合している |
> | **可能性** | ひとつの記録からの推測 |
> | **判定不能** | 必要な記録が存在しない／取得できなかった |

## 2. 確認した範囲

実際に取得し、目を通したもの。

- [ ] 揮発性データ（プロセス・ネットワーク接続・ログイン中セッション）
- [ ] ログインセッション履歴（`last` / `lastb` / `lastlog`）
- [ ] システムログ（auth.log / syslog / Web サーバー / Docker）
- [ ] 認証設定（passwd / group / sudoers / sshd_config / PAM）
- [ ] `authorized_keys` 全探索（ホームディレクトリ外を含む）
- [ ] sshd 実効設定（`AuthorizedKeysFile` の変更有無）
- [ ] AI エージェントのセッションログ
- [ ] 永続化ポイント（cron / at / systemd / ld.so.preload / シェル初期化）
- [ ] SUID/SGID
- [ ] MAC タイムライン

---

## 3. 未確認の範囲

取得していない、または確認していないもの。**空欄にしない。**

- [ ] カーネルモジュール / eBPF（高度調査を実施していない）
- [ ] メモリイメージ
- [ ] **クラウド管理プレーン**（IAM / startup-script / スナップショット共有 / 監査ログ設定）
- [ ] 完全ディスクイメージ
- [ ] 秘密鍵・shadow・認証トークンの**本文**（指紋のみ収集）

> [!CAUTION]
> **クラウド管理プレーンは、ホスト内からは検出できない。**
> OS 側のバックドアを全て除去しても、IAM に管理者キーが残っていれば再侵入される。
> `persistence_hunting.md` の Tier 3 チェックリストを手で実施すること。

---

## 4. 検出の限界

```
本調査は侵害ホスト自身のコマンド（bash / ps / ss / find）を使用している。
ルートキットが導入されている場合、収集結果自体が偽装されている可能性がある。

確実な保全は、ホストを停止してディスクイメージを外部から取得すること。
クラウドであれば管理プレーンからのスナップショットを優先する。
```

その他、本件で該当するもの:

- [ ] `.bash_history` にタイムスタンプがない（`HISTTIMEFORMAT` 未設定）
      → 記録順は実行順ではない。シェル終了順に追記される
- [ ] SSH 認証ログに公開鍵フィンガープリントを含む該当エントリがない
      → 使用鍵と実行者をログから対応付けできない（ログ未保全、古い OpenSSH、ログ形式・出力先の差を確認）
- [ ] `/var/log/journal` が存在しない
      → journald が揮発設定。過去のブートのログは存在しない
- [ ] アクセス時刻(atime)が収集処理自身により汚染されている可能性

### 記載例

| # | 内容 | 根拠 | 確度 |
|---|---|---|---|
| 1 | UID 0 のアカウント `system` が存在 | `auth/uid0_users.txt` | **確定** |
| 2 | `/usr/.system/.ssh/authorized_keys` に未知の公開鍵 | `auth/all_authorized_keys.txt` | **確定** |
| 3 | 上記の鍵が SSH 認証に使用可能な配置だった | `system` のホームが `/usr/.system` か未確認 | **可能性** |
| 4 | 外部侵入者による操作である | 鍵の出所を説明できる記録がない | **強く示唆** |
| 5 | 侵入日時 | auth.log が存在しないため特定できない | **判定不能** |

> [!IMPORTANT]
> 3番のような「一段確度を落とす」判断を省かない。
> ひとつのレイヤーの証拠から、隣のレイヤーの結論を出さないこと。
