# 平時演習 — 使い捨て環境で一度転んでおく

> [!IMPORTANT]
> **封じ込めコマンドを、本番で初めて実行してはいけない。**
>
> 構文チェックとレビューを通っても、実環境で動くかは別の話。
> 実際、本スキルの iptables コードは査読を3周し、構文チェックも通したうえで、
> **初回実行時に実行者を締め出した。**
>
> 原因は **受信側の許可漏れ**だった。SSH だけを考えて INPUT を絞った結果、
> 作業に使っていたツールが受信してくる接続まで落ちた。
> 送信側（curl など）は問題なく通っていたため、原因の切り分けにも時間がかかった。
>
> 図面を何度見直しても、非常口が実際に開くかは分からない。開けてみるまでは。
> そして訓練は、**燃やしてもいい建物でやる。**

---

## いつやるか

- 新しいサーバーを構築したとき
- 封じ込め手順を変更したとき
- **最低でも年1回**

環境は勝手に変わる。カーネルが上がって挙動が変わる、Docker を入れて FORWARD 経路が増える、
SSH ポートを変える、IPv6 が有効になる。**去年通った訓練が、今年も通る保証はない。**

所要時間は15分程度。

---

## 何を確認するか

| # | 確認項目 | 落ちるとどうなるか |
|---|---|---|
| 1 | **受信を必要とするサービスの洗い出し** | **SSH 以外の受信が全部落ちる（監視・エージェント・管理系）** |
| 1b | `conntrack` が使えるか | 既存接続の保護が効かず、自分ごと切れる |
| 2 | `ip6tables` が存在するか | IPv6 が素通し、または適用途中で停止 |
| 3 | インターフェース名が実在するか | 許可ルールがマッチせず DROP に落ちる |
| 4 | SSH の実待受ポート | 22 を許可しても再接続できない |
| 5 | ロールバックで完全に戻るか | 戻したつもりで残る |
| 6 | デッドマンスイッチが動くか | 締め出されたら終わり |
| 7 | `at` / `cron` が使えるか | 自動ロールバックを仕掛けられない |
| 8 | コンソール（VNC/シリアル）で入れるか | SSH を閉じたら復旧手段がない |

**1番が最重要。** 実際の事故はここで起きた。
`ESTABLISHED,RELATED` は「いま繋がっている接続」しか守らない。
**新しく張られてくる接続はすべて DROP される。**

## Docker での演習

```bash
docker run -it --rm --cap-add=NET_ADMIN --name ir-rehearsal ubuntu:24.04 bash

# コンテナ内で
apt-get update && apt-get install -y iptables iproute2 at
bash rehearse_containment.sh
```

> [!NOTE]
> Docker は「管理系が外から接続してくる」構造を再現しやすい。
> 本スキルの事故もこの形で起きた。適用した瞬間、
> **送信は通るのに、次のコマンドが実行できなくなった。**
>
> なお conntrack は Docker でも使えることが多い。
> 「conntrack が無いから切れた」と決めつけないこと（実際、最初の診断は外れた）。

### Docker で確認できないもの

- 実際の SSH 切断挙動（コンテナは SSH 経由ではない）
- コンソールからの復旧
- systemd 配下でのファイアウォール永続化
- クラウドのメタデータサーバーへの到達性

これらは使い捨て VM で確認する。

## 使い捨て VM での演習

```bash
# クラウドの最小インスタンスを1つ立てる
# 必ず: コンソールログインが使えることを「先に」確認する
#       （鍵認証のみの設定だと、コンソールから入れない場合がある）
# 演習後は破棄する
```

> [!CAUTION]
> **演習用インスタンスには、本番の鍵も認証情報も置かない。**
> 締め出されて破棄することが前提の環境なので。

## 演習の流れ

```
1. 環境チェック          rehearse_containment.sh（変更なし）
2. デッドマンスイッチ設置  3分後に自動ロールバック
3. 適用                  実際に隔離チェーンを入れる
4. 検証                  別端末から入れるか / Tailscale は生きているか
5. ロールバック          手動で戻す
6. 再検証                チェーンが完全に消えたか
7. デッドマンスイッチ解除  atrm
```

**4で入れなかった場合は、何もせずに待つ。** 3分後に自動で戻る。
これを確認するのが演習の目的のひとつ。
